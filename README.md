# Main Code
This folder contains the core implementation of MSGL-BSF, which is divided into three subdirectories: code, data, and bert.
- code/: model implementation, training, evaluation, and general utility functions
- data/: dataset path descriptions; raw data is stored in the project root directory
- bert: scripts for BioMedBERT semantic encoding

The main training entry is code/train_liquid_neighbor_sequence.py, and the one-click running entry is code/run_msgl_bsf.py.
